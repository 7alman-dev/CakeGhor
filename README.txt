# CakeGhor Demo Website

A responsive, frontend-only cake shop preview.

## Files
- `index.html` — page structure
- `style.css` — responsive visual styling
- `script.js` — sample products, Bangla/English toggle, filters, cart, order preview
- `assets/` — flat vector cake illustrations

## Run locally
1. Extract the ZIP.
2. Open the `CakeGhor` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Test desktop and mobile widths using browser DevTools.

## Demo limitations
- No backend, database, authentication, payment or real API.
- Cart data is kept only in the current browser session and resets on refresh.
- Delivery areas and charges are fictional sample data.
- Order Now opens WhatsApp with a pre-filled demo message using the no-number contact-selection link. No real number is configured, and nothing is sent unless a user chooses a contact and presses Send.
- Google Fonts need an internet connection; fallback fonts are included.
